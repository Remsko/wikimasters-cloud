# WikiMasters Cloud

Tableau de bord pour piloter à distance l'ouverture des packs WikiMasters
(lancer / arrêter, mode 10 par 10, top 10 des cartes du jour).

Site : https://remsko.github.io/wikimasters-cloud/

Fonctionne avec le script « WikiMasters – Outils » (version 4.0 ou plus) :
sur le PC qui sert de cloud, cocher « Ce PC est le cloud de mon compte ».
