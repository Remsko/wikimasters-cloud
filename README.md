# WikiMasters Cloud

Tableau de bord pour piloter à distance l'ouverture des packs WikiMasters
(lancer / arrêter, mode 10 par 10, top 10 des cartes du jour, partie admin).

- Site : https://remsko.github.io/wikimasters-cloud/
- Script (installation en un clic avec Tampermonkey) : https://remsko.github.io/wikimasters-cloud/wikimasters-outils.user.js
- Lanceur Windows : https://remsko.github.io/wikimasters-cloud/lanceur/WikiMasters-Cloud-lanceur.zip

Le lanceur tourne sur le PC cloud : il ouvre la fenêtre Chrome (profil séparé) d'une personne
quand elle touche « Lancer » sur le site, et la ferme quand elle touche « Arrêter ».
